Website Personal Trainer
Este projeto consiste em um site responsivo desenvolvido para um Personal Trainer, servindo como uma plataforma de apresentação de serviços, divulgação de visão de trabalho, depoimentos de clientes e um canal de comunicação direta para agendamento de aulas experimentais.

🚀 Sobre o Projeto
O site foi idealizado para oferecer uma presença digital profissional, focada na conversão de visitantes em clientes. A interface é limpa, utilizando uma paleta de cores que remete a energia e vigor, alinhada ao nicho de fitness.

Principais Funcionalidades:
Página Inicial: Apresentação visual com carrossel de imagens e destaque para agendamento.

Sobre Nós: Espaço para contar a história e a metodologia do profissional.

Nossa Visão: Detalhamento dos pilares de trabalho (Tônus Muscular, Força Abdominal, Correção de Postura, etc.).

Depoimentos: Seção para exibir feedbacks de alunos.

Blog: Área destinada a conteúdos e dicas fitness.

Inscrição: Formulário de contato para que novos clientes possam solicitar agendamentos.

🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido com foco em simplicidade, responsividade e manutenção, utilizando:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização personalizada, com foco em design responsivo (Media Queries).

Bootstrap 4.6.2: Framework CSS para agilizar o layout e garantir a responsividade em diferentes dispositivos.

FontAwesome: Utilizado para ícones visuais na interface.

jQuery: Utilizado para funcionalidades de interatividade (como o carrossel do Bootstrap).

📂 Estrutura do Projeto
index.html: Página principal.

sobre.html: Detalhes sobre o profissional.

visao.html: Metodologia e visão de trabalho.

depoimento.html: Feedback dos alunos.

inscreva.html: Página de contato/agendamento.

academia.css: Folha de estilos personalizada.

Como utilizar
Para rodar o projeto localmente, basta clonar este repositório e abrir o arquivo index.html diretamente no seu navegador.
